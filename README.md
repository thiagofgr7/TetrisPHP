# TetrisPHP

Projeto de Tetris em PHP, MySQL, HTML, CSS e JavaScript.

## Executar localmente

1. Inicie o MySQL e importe `database/schema.sql`.
2. Na raiz do projeto, execute:

   ```bash
   php -S 127.0.0.1:8000
   ```

3. Acesse [http://127.0.0.1:8000/](http://127.0.0.1:8000/).

O servidor embutido do PHP é destinado somente a desenvolvimento local.
